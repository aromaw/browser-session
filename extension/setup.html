New Session

在当前网页点击工具栏按钮，即可用全新身份打开同一网址。

一次性设置

  1. 将 browser-session 可执行文件放在固定位置，并确保 Chrome 已安装。
  2. 在该文件所在目录打开终端，执行下方命令。
  3. 将本扩展固定到工具栏。回到任意普通网页，点击 New Session。
Windows 使用 .\browser-session.exe；macOS / Linux 使用 ./browser-session。macOS / Linux 如无法执行，先给 binary 添加执行权限。
按钮出现 ! 时
  • 确认当前地址以 http:// 或 https:// 开头；Chrome 设置页、新标签页和本地文件不支持。
  • 确认本机组件已经注册，安装后没有移动或删除可执行文件。
  • 如果已有新窗口弹出，请先检查它，不要反复点击；可用 browser-session list 查看状态。
  • 使用自定义 Chrome 用户数据目录时，安装命令增加 --chrome-data-dir "完整目录路径"。
会话如何结束？
退出新窗口所属的 Chrome 实例后，后台看护程序确认全部进程退出，再删除临时 Profile。macOS 可能需要在该实例中选择“退出 Google Chrome”。原窗口不受影响。
新 Profile 不会自动安装扩展。需要再开一个身份时，回到原来的浏览器点击 New Session。当前网址会传给本机组件；不会复制账号、Cookie 或页面表单，也不会上传到网络。
插件不需要管理器 GUI 常驻。不使用 Cookie 替换、代理或指纹伪装。
